# 前端质量自检清单

交付前逐项检查；任何一项不过即返工。

## 功能与交互

- [ ] 所有按钮、链接、表单控件都有真实行为，无死控件（placeholder 点击无响应算 bug）。
- [ ] 加载/空/错误三态都有 UI，不是白屏或裸报错。
- [ ] 表单有校验提示；提交有 pending/成功/失败反馈。
- [ ] 路由切换正常，浏览器前进后退可用；深链直达不白屏。

## 响应式

- [ ] 375px（手机）、768px（平板）、1280px+（桌面）三档无横向滚动条、无元素重叠。
- [ ] 触屏目标 ≥ 44×44px；hover 效果在触屏上有等价反馈。
- [ ] 图片 `max-width: 100%`，文本在窄屏不溢出。

## 视觉与动效

- [ ] 配色有主色/中性色/语义色（成功/警告/错误），对比度正文 ≥ 4.5:1。
- [ ] 暗色模式所有页面可用（如项目要求）。
- [ ] 动效有目的（反馈/引导/过渡），时长 0.15–0.5s，见 animation.md。
- [ ] 数字、价格、日期格式统一；无 lorem ipsum 残留。

## 工程

- [ ] `npm run build` 通过，无 TS 错误、无未使用变量警告。
- [ ] 无 `console.log` 残留、无硬编码密钥/内网地址。
- [ ] 大列表有 key 且稳定；图片懒加载。
- [ ] 文案中提到的数据与界面显示一致。

## 可访问性

- [ ] 语义化标签（header/nav/main/footer/button 而非 div+onClick）。
- [ ] 图标按钮有 `aria-label`；图片有 `alt`。
- [ ] 键盘 Tab 可达且顺序合理；focus 样式可见。

## 固定导航栏专项

- [ ] 固定/吸顶导航**任何滚动位置**都不与正文「文字叠文字」：始终给导航背景（毛玻璃/实色），透明导航只在首屏背景简单的页面用。
- [ ] 锚点跳转的目标区块有 `scroll-mt-*`（或 `scroll-margin-top`），标题不被固定导航遮住。
- [ ] 导航中的每个链接都指向真实存在的区块 id，无死链。
- [ ] 首屏主标题与导航的比例协调（经验值：标题最大字号 ≤ 导航栏高度的 6–7 倍）。

## 无边框窗口专项

- [ ] 最小化/最大化/关闭三个按钮**真实可用**（在真机 Tauri 窗口里点过，不是只在浏览器里看）。
- [ ] 窗口可拖拽：顶部空白区按住能移动窗口，岛上按钮/链接仍可点击（pointer-events 分层正确）。
- [ ] 最大化后按钮图标切换为「还原」，且能正常还原。
- [ ] 关闭按钮 hover 变红。
- [ ] capabilities/default.json 已追加 5 个 `core:window:allow-*` 权限。
- [ ] 浏览器预览时窗口按钮自动隐藏（不出现死按钮）。
